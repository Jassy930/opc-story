# OPC 一人公司物语

开罗风像素经营游戏：你一个人带着一群 AI agent 开公司。接单赚钱、控制 token 成本、跟上模型迭代，目标是现金达到 ¥1,000,000。

## 运行

无构建、无依赖。直接双击 `index.html` 用浏览器打开即可。

```bash
open index.html     # macOS
bun test            # 跑逻辑测试（含 720 天自动对局的平衡性检查）
```

## 玩法

- **选方向**：编程外包（大单）/ 内容工作室（小单多）/ 客服 SaaS（交付后带来月订阅收入）。方向决定订单类型分布和初始 agent 职业。
- **Agent**：每个 agent 有职业（程序员/写手/客服）、等级、使用的模型。做匹配职业的项目产出 ×1.5；交付后有概率升级。最多 8 个工位，招募越多越贵。
- **Token 成本**：只有在干活的 agent 才烧 token，每天成本 = 消耗量 × 模型单价。空闲不花钱，但每月仍有固定运维费。
  - 全局模式：省钱（token ×0.5，产出 ×0.65，质量 -5%）/ 标准 / 深度思考（token ×2，产出 ×1.4，质量 +5%）。
- **模型**：每个模型有单价、产出、质量。质量低于订单要求会少拿钱、掉声誉；逾期则合同取消。新模型按时间线发布，老模型会下线（agent 被强制迁移），偶尔有价格战/涨价。换模型要付迁移费。
- **事件**：推文爆火、幻觉事故、提示词注入、API 限流、投资人注资、监管新规……
- **胜负**：现金 ≥ ¥100 万胜利；现金 < 0 破产。

## 文件

| 文件 | 内容 |
| --- | --- |
| `data.js` | 方向、职业、项目类型、模型时间线、名字池（调数值改这里） |
| `sim.js` | 纯游戏逻辑（无 DOM），`tick()` 推进一天 + 玩家操作 + 随机事件 |
| `game.js` | canvas 像素办公室渲染 + 右侧面板 + 主循环 |
| `sim.test.js` | `bun test`：token 扣费、破产、模型发布/切换/下线、平衡性 |

## 平衡基线

自动玩家（只接单+招人，从不换模型、不调模式）约 1.5~2 年达成目标；测试保证它 90 天内不破产、300 天内不会通关。改数值后跑一次 `bun test` 看输出。
