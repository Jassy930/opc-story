# OPC 一人公司物语

开罗风像素经营游戏（回合制）：你一个人带着一群 AI agent 开公司。接单赚钱、控制 token 成本、跟上模型迭代，目标是现金达到 ¥1,000,000。

## 运行

无构建、无依赖。直接双击 `index.html` 用浏览器打开即可。进度每天自动存到浏览器 localStorage，重新打开可「继续上局」。

```bash
open index.html     # macOS
bun test            # 跑逻辑测试（含 720 天自动对局的平衡性检查）
bun balance.js      # 数值分析：多种策略各跑 20 局，对比通关天数/破产率/成本结构
```

## 玩法

游戏是**回合制**：每点一次「下一天 ▶」（或按空格）推进一天，之后看日报。两次点击之间可以随便操作，时间不会走。

- **⏩ 推进到有事发生**（或按 F）：连续过天，遇到交付/逾期/资讯/抉择事件/模型快讯/agent 闲下来/现金跌破 ¥1 万就停，最多 30 天。日报顶部会写停下的原因。
- **自动接单**：只接「团队平均质量 ≥ 订单要求，且按现有排期做得完」的单，按单位报酬从高到低接，每接一单写日志。
- **低精力自动休息**：精力 < 30 时当天改为休息，不会改掉你选的行动。

- **选方向**：编程外包（大单）/ 内容工作室（小单多、来单快、单价高）/ 客服 SaaS（交付后带来月订阅收入）。方向决定订单类型分布和初始 agent 职业。
- **Agent**：每个 agent 有职业（程序员/写手/客服）、等级、经验、使用的模型。做匹配职业的项目产出 ×1.5；每干一天活 +1 经验，满了升级（最高 Lv5）。最多 8 个工位，招募越多越贵。
  - 每个 agent 可以**手动指派项目**，不指派就自动分配（优先同类型、最早截止）。项目结束后自动回到自动分配。
- **CEO 每日行动**（你自己）：日常管理 / 休息 / 跑客户（带回新单）/ 亲自把关（当天质量 +10%）/ 调提示词（全员经验）/ 发推营销（声誉）。行动消耗或恢复精力，精力低于 20 时全员质量 -5%。选中的行动会一直保持，精力不够时自动改为日常管理。
- **Token 成本**：只有在干活的 agent 才烧 token，每天成本 = 消耗量 × 模型单价。空闲不花钱，但每月仍有固定运维费。
  - 全局模式：省钱（token ×0.5，产出 ×0.75，质量 -5%，现金紧张时止血）/ 标准 / 深度思考（token ×2.2，产出 ×1.3，质量 +5%，赶工期用，常开容易破产）。
- **订单**：质量要求越高报酬越高（按 (要求/0.7)² 缩放），内容类小单单价 ×1.3。交付质量超出要求最多多拿 15%，不达标按差距平方扣钱并掉声誉；逾期则合同取消。
- **模型**：每个模型有单价、产出、质量。没有万能模型：最便宜的接不到高要求单，最贵的利润被 token 吃掉，最赚的是在满足质量要求的模型里挑「日利润 = 产出 × 单位报酬 − token 费」最高的，新模型发布后值得重新算一遍。新模型按时间线发布，老模型下线时 agent 会被厂商强制迁移到**自家最新模型**（比如 Claudia 3.5 → Claudia 4 Opus，账单翻倍，要自己盯着换），偶尔有价格战/涨价。换模型要付迁移费。
- **公司升级**：官网 SEO、Prompt 模板库、监控告警、Prompt Caching、RAG、Evals、模型路由器、多 Agent 编排，一次性购买，永久生效（降 token、提产出/质量、免疫某些事故）。
- **资讯事件**（自动生效）：推文爆火、幻觉事故、提示词注入、API 限流、价格战、刷榜丑闻、监管新规……
  - 业界梗：CEO 被董事会开除又回归、吉卜力风刷屏、9.11 比 9.9 大 / strawberry 数 r、agent 删生产库、客服被诱导「1 元购车」、律所引用不存在的判例、春节红包大战、Vibe Coding 爆火、API key 写进前端被刷、MCP 成标配、发布会图表画错、模型「勒索工程师」、人形机器人马拉松掉头、#还我旧模型 运动（下线的模型复活 30 天）。
- **抉择事件**（弹窗必须选）：客户加急、需求变更、竞品抢单、买断 Prompt 库、投资人注资、数据泄露、开源赞助、黑客松、年付套餐（模型 5 折）、新模型内测、大厂收购。
  - 业界梗：邀请码被炒到 ¥999、让 agent 经营自动售货机（可能进一批钨块）、大厂亿元年薪挖人、投标书藏白字提示词注入、晒月入被质疑 P 图、一人公司纪录片跟拍。
  - 所有厂商、模型名都是谐音虚构，不涉及真实人物。
- **结局**：现金 ≥ ¥100 万胜利；接受大厂收购进入收购结局；接受亿元年薪挖人进入打工人结局。现金为负时进入透支（额度 ¥2 万，日息 0.5%），超过额度才破产。

## 平衡基线

改数值后跑 `bun balance.js`（默认每格 20 局，可传 `bun balance.js 30 keep,margin` 指定局数和策略）。**看各策略的排序方向，不看绝对数。**

策略：`naive` 只接单招人、从不换模型；其余都开自动接单/自动休息、买升级、用 CEO 行动，区别只在模型策略——`keep` 从不换、`cheap` 永远单价最低、`best` 永远质量最高、`smart` 满足项目要求的最便宜、`margin` 满足要求且日利润（产出×单位报酬−token 费）最高；`:eco` / `:turbo` 后缀为常开省钱/深度思考。

当前结果（30 局，2026-10-30），通关中位天数按 编程 / 内容 / 客服：

| 检查项 | 期望方向 | 当前结果 |
| --- | --- | --- |
| 模型选择有回报 | 主动按利润换模型最优，不管模型明显吃亏 | margin 230 / 261 / 239；keep 269 / 330 / 275，D180 现金约为 margin 的一半 |
| 没有万能模型 | 永远最贵更慢更穷，永远最便宜接不到单 | best 245 / 325 / 256；cheap 520~580 天且 20~30% 破产 |
| token 是主要成本 | token 占支出大头；会玩的人占收入 ~25%，乱用的 40%+ | 占支出 83~93%；占收入 margin 24~28%，best/keep 39~45% |
| 模式各有用处 | 无常开最优 | 常开省钱慢 ~10% 但稳；常开深度思考在编程/客服略快但破产 10~30%，内容方向明显亏 |
| 三个方向接近 | 差距不超过 ~15% | margin：230 / 261 / 239 |
| 新手不会秒死 | 90 天内基本不破产 | naive 破产都发生在模型强制迁移之后（D105 起） |

`bun test` 里的平衡断言：自动玩家 150 天内不会通关，每个方向 5 局里最多 1 局在 90 天内破产。
